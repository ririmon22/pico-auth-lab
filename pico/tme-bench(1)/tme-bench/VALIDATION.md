# 配布版の検証記録

2026-10-06作成。実行環境はLinux x86-64 / GCC 13.3.0 / KVM仮想CPU。
ここでのoff/onは比較ツール動作検証用のラベルで、TMEを切り替えた測定ではありません。
その数値は性能評価結果として配布しません。

実施済み：

- GNU C99、O3、Wall/Wextra/Wpedantic/Werrorで警告なしビルド。
- 通常storeとNT storeが全バイトを書き、前後64Bのcanaryを変更しない検証。
- 固定seedによるポインタ列が全キャッシュラインを重複なしで一周する検証。
- 依存loadループが1周後に先頭へ戻る検証。別の10 seedでも1周を確認。
- 4テスト各3試行の実行、CSV出力と有効試行の統計。
- 通常write＋CLFLUSH追加モードの実行とCSV。
- 負のCPU、範囲外CPU、size=0、NaN時間、seed=0、不正THPの拒否。
- CSVの既存ファイル上書き拒否。
- run.shの環境・ハッシュ保存とcompare.pyの連携。
- 比較式、一定値のbootstrap区間、無効試行・switch除外・ラベル不一致の単体検証。
- bash構文チェック。
- 逆アセンブルでSSE2 load、MOVNTDQ、CLFLUSH、RDTSCPの存在を確認。

未実施：

- 対象Intel Core実機での動作確認。
- BIOS TME OFF/ONの実切り替え、MSR状態の照合、DRAM/IMC計数との照合。
- 数時間の連続実行、16 GiB領域、複数NUMA node、巨大ページの実確保、mlock成功条件。

最初に実機でmake checkと短い動作確認を行い、CPU型番・BIOSを記録して本計測してください。

- 既知の配列{1,2,3,4}で平均、中央値、p95、母／標本標準偏差を検証。
- 1試行の標本標準偏差は未定義として扱う検証。
- 4テストの生CSVからPython標準statisticsで独立に再計算し、集計CSVと一致を確認。
- 単位、平均スループット／平均レイテンシの列分離、集計ファイル上書き拒否を確認。
